# Changelog

All notable changes to this repository are listed here.

## [1.0.0] - November 2026

First release: the code for **Python + AI: Build 100 AI Agents, Volume 1, Part A (Agents 1 to 25)**.

- 25 agents in five levels: Agent Basics, Everyday Assistants, Web & Search, File & Document, Email & Messaging.
- Sample data for every chapter (invented for learning).
- `run_all_agents.py`: one command that runs all 25 agents and compares them with the expected outputs.
- Checked with Python 3.9 to 3.13.
